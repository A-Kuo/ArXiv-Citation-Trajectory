## Summary
Citation-trajectory prediction has moved decisively toward temporal graph neural networks and LLM-based scoring of early-life papers, with 2024–2025 work focused on disentangling diffusion/conformity/contribution effects and on centrality-aware dynamic graphs. The strongest applicable finding is CDCHGN (dual clustering-driven, centrality-guided temporal GNN), which beats prior SOTA on the APS citation dataset — a good architectural reference for this repo's temporal transformer. LLM-based "newborn article" impact scoring is also emerging as a way to handle cold-start papers with no citation history yet, which is a known weak spot for pure graph-based approaches.

## Engineering Insights
- Use a standardized benchmark (OAG-bench-style task/metric split) rather than a custom train/test split, so results are comparable to published SOTA numbers.
- Node/author centrality (degree, betweenness, PageRank) is a cheap, high-signal feature that keeps showing up across multiple 2024–2025 papers — worth adding before reaching for heavier temporal-transformer architectures.
- Decompose citation growth into diffusion vs. conformity vs. genuine contribution as auxiliary loss terms; this improves interpretability of the trajectory model beyond a single citation-count regression target.
- For cold-start papers (zero citations at t=0), fall back to an LLM-based content/impact scorer rather than relying purely on graph structure, which has no signal yet for brand-new nodes.
- Follow standard ML production deployment practice: define explicit performance baselines (e.g., MALE/RMSLE thresholds), add real-time monitoring for prediction drift, and build a retraining loop as citation data updates over time (per general ML deployment guidance from Medium/ScienceDirect sources).

## Recommended Next Actions
1. Add an author/node-centrality feature module (degree, betweenness, PageRank) to the existing graph pipeline — cheap addition with strong empirical support across multiple 2024–2025 papers.
2. Prototype a CDCHGN-style dual clustering + centrality-guided attention layer as an alternative/complement to the current temporal transformer, and benchmark MALE/RMSLE against the existing model.
3. Add a cold-start path: for papers with no citation history, score impact via an LLM-based content classifier (per the AAAI25 "From Words to Worth" approach) and blend with the graph-based prediction once citations start accruing.
